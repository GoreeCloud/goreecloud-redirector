# Privacy

GoreeCloud Redirector is local-first and does not collect or transmit user data.

The extension does not use analytics, telemetry, advertising, remote logging, content scripts, remote code, remote fonts, or remote icon libraries. Redirect rules are evaluated by Firefox through `declarativeNetRequest`.

The built-in redirect requires host access only to `https://keep.google.com/*`. A custom redirect requests a source-site host permission only when the user explicitly saves or enables that rule. Custom rule metadata is stored in Firefox local extension storage.

The extension does not send browsing activity, URLs, redirect definitions, settings, or interaction data to GoreeCloud or any third party.
