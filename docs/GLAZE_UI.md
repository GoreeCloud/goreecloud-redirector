# Glaze UI Conformance

Target: Glaze UI 1.0.0.

GoreeCloud Redirector maps the canonical Glaze UI semantics into a compact browser-extension interface. The extension uses the canonical light/dark canvas, surface, text, line, accent, secondary-accent, and danger values; 16 px control radii; 22 px panel radii; 44 px minimum interactive targets; 160 ms Fast motion; and the standard 3 px focus treatment.

The interface includes layered surfaces, selective translucency, a purposeful GoreeCloud blue-to-violet accent gradient, local/system fonts, local icon assets, reduced-motion behavior, increased-contrast treatment, forced-colors behavior, and a solid fallback when backdrop filtering is unavailable.

No remote UI dependency is permitted. Visual acceptance of the popup on Firefox has been completed for v0.1.0 functionality. v0.2.0 requires final acceptance after the signed package is installed persistently.
